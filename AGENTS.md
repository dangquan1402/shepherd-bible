# Project agent memory

This file is the project's committed home for project-intrinsic agent knowledge: build, test, release, architecture, and sharp-edge notes that should travel with the code.

- The app is **Pasture** (renamed from Shepherd on 2026-10-06; App Store name "Pasture: Daily Bible Path"). Every user-visible string, the wordmark and the StoreKit display names say Pasture. The internal identifiers deliberately keep Shepherd: the Swift module, targets and folders, `Shepherd.xcodeproj`, the `.pen` file names, the bundle id and product ids `com.dangvietquan.shepherd*`, and the repo name. Never rename them. `ShepherdTests/testUserVisibleNameIsPasture` guards the display name and the StoreKit names.
- Design lives in `design/`: `shepherd.lib.pen` (tokens + components), `screens/shepherd.pen` (imports it as alias `I`), PNG exports, and the spec in `design/README.md`. The README's token, component, frame and sample-content sections are generated: run `python3 design/tools/readme_tables.py` after changing a `.pen`.
- Edit `.pen` files only through Pencil (app, MCP, or headless `pen interactive` with a safe-save that checks `list_libraries()` is ok). Never hand-edit the JSON; a broken library link or a renamed variable silently flattens token bindings.
- Every top-level screen frame must set `theme: {"I:mode": "light"|"dark"}`, or library bindings render black.
- Release (TestFlight): `tools/archive.sh <build-number>` archives, exports and runs `tools/verify_ipa.sh` (manual signing, "Shepherd AppStore Profile", team 6KH82C884Q); bump the build number each upload. Call asc only as `asc --profile LittleRed ...` (app 6819303372); never `asc auth switch`, never another team's profile.
- Scripture, lesson and quiz text in designs must come verbatim from `Shepherd/Resources/Content/*.json` (WEB). Green/red are reserved for quiz correctness.
- Bible text (`web.json`, WEB `engwebp`) is generated by `tools/bible/build_web.py` from a SHA-256-pinned eBible zip; never hand-edit it (the "World English Bible" name is only allowed for unchanged text, punctuation included). Lesson content (`paths.json`) must pass `python3 -I tools/content/validate_content.py` (`--release` also rejects `draft` paths) and `python3 -I -m unittest discover -s tools/content`; every quiz question needs an `answerRef` proof verse among the lesson's `verseRefs`. Lesson ids are global progress keys: never rename one.
- `ShepherdTests/StoreKitTests` hangs in a fresh simulator clone (SKTestSession errors); run unit tests with `-only-testing:ShepherdTests/ContentTests -only-testing:ShepherdTests/ShepherdTests` when it does.
- Brand (Flock) source of truth is `tools/brand/`: colours in `tokens.py` (`python3 tools/brand/tokens.py check flock` is the AA gate), the lamb in `lambgen.py` (generated, never hand-drawn). `apply_design.py` writes both into the `.pen` files and `apply_app.py` writes colour sets, `lamb_variants.json`, AppIcon, TabLamb and wordmark. The wordmark text is set in `brandart.py` `WORDMARKS`; regenerate `wordmark.json` from Baloo 2 (`google/fonts` `ofl/baloo2/Baloo2[wght].ttf`). Change a colour or the lamb there, then re-apply to both sides. The scripts need shapely and resvg_py.
